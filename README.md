# Desert Sandstorm Datapack

## Overview
The Desert Sandstorm Datapack enhances your Minecraft experience by introducing dynamic sandstorm weather events that can affect gameplay. This datapack brings both aesthetics and functionality, creating a new layer of challenge in desert biomes.

## Features
- **Dynamic Sandstorms:** Create visual and gameplay effects during sandstorm events.
- **Survival Challenges:** Players may experience reduced visibility and increasing hunger during a sandstorm.
- **Customizable Frequency:** Adjust how often sandstorms occur.

## Installation Instructions
1. **Download the Datapack:** Obtain the datapack from the release link or repository.
2. **Locate Your World:** Navigate to the `datapacks` folder in your world save directory.
3. **Install the Datapack:** Place the downloaded `.zip` file (or extracted folder) into the `datapacks` directory.
4. **Enable the Datapack:** Open your world and use the command `/reload` or load the world to activate the datapack.

## Usage
- Sandstorms will activate automatically based on configured frequency.
- Players can experience the effects by visiting desert biomes during a sandstorm.

## Configuration Options
- The frequency of sandstorms can be adjusted in the configuration file located at `data/sandstorm/config.json`.
- Configuration settings include:
  - `sandstorm_frequency`: Set how often sandstorms occur (in ticks).
  - `visibility_reduction`: Adjust how much visibility is reduced during a sandstorm.

## Requirements
- **Minecraft Version:** Compatible with Minecraft Java Edition 1.16 and above.
- **No Mods Needed:** This datapack functions without any additional mods.

## Troubleshooting
- **Datapack Not Working:** Ensure it is correctly installed in the `datapacks` folder and enabled.
- **Sandstorms Not Occurring:** Check the configuration settings to ensure a valid frequency.
